# 🌿 Well Mate AI – AI-Powered Wellness Assistant

## 📌 Project Description
Well Mate AI is an AI-powered wellness application designed to help users maintain a healthy and balanced lifestyle. It provides personalized diet plans, exercise routines, meditation activities, stress management guidance, and wellness tracking based on users' profiles and preferences.

## 🎯 Objectives
- Provide personalized wellness recommendations.
- Encourage healthy eating and regular exercise.
- Help users monitor their daily wellness progress.
- Support stress management and mindfulness.
- Improve accessibility through chatbot and voice assistant features.

## ✨ Features
- 👤 **User Profile:** Collects basic details, preferences, and wellness goals.
- 🥗 **Food & Diet:** Provides personalized food suggestions and diet plans.
- 🏃 **Exercise:** Offers fitness routines and exercise recommendations.
- 🧘 **Wellness:** Supports meditation and stress management activities.
- 📊 **Track Progress:** Tracks mood, sleep, water intake, and daily activities.
- 🔔 **Notifications:** Provides reminders for wellness activities.
- 🤖 **AI Chatbot:** Offers wellness-related assistance.
- 🎙️ **Voice Assistant:** Aims to make the application easier to use through voice interaction.
- 🚨 **Emergency Support:** Provides quick access to emergency-support information.

## 🛠️ Technologies Used
- Flutter
- Dart
- AI and chatbot integration
- Backend services and database (as implemented)

## ⚙️ How It Works
1. Users create their profile and enter their preferences.
2. The application uses the available profile information to personalize wellness suggestions.
3. Users access diet plans, exercise routines, and meditation activities.
4. Users track their daily progress and provide feedback.
5. Notifications help users maintain consistent wellness habits.

## 🚀 How to Run
1. Install Flutter and Dart.
2. Install and open Android Studio.
3. Clone or download this repository.
4. Open the project folder in Android Studio.
5. Install the required dependencies.
6. Connect an emulator or Android device.
7. Run the application.
